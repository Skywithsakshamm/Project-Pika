# 🤖 Project Pika

Project Pika is a Python AI voice assistant that converts text into natural Hindi speech using Microsoft Edge TTS.

## Features
- 🎙️ Hindi AI Voice
- ⚡ Fast Voice Generation
- 🐍 Built with Python
- 🔊 Saves audio as MP3

## Technologies
- Python
- Edge-TTS
- Asyncio

## Installation

```bash
pip install edge-tts
```

## Run

```bash
python main.py
```
